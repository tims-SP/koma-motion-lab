# P15-65 · 近眼下眼睑修边与前发遮挡实测

## 目标及输入
- 复用 Git 48bdf0f 所记录的 P15-64 近眼 ArtMesh 候选、P15-63 LaMa 遮挡底图及 P15-56 右向原画。正式 ArtMesh、P0 原画和关键帧不改。
- 只解决下眼睑晕边、眼睛移动时与前发的遮挡质量，保持 0/9/18px 实际可渲染移动。

## 实际执行及判断
- 生成并逐张查看 12 张局部修边对照：原轮廓、下眼睑收紧约 2/4/6px，各测试 0.75/1/1.5px 羽化。
- 采用“下眼睑收紧约 2px + 1px 羽化”的候选。和 P15-64 比，下眼睑灰色晕边减轻；收紧 4px/6px 会削弱虹膜底部和下眼缘的自然轮廓。
- P15-64 原近眼可见图层非透明像素 6,995；P15-65 为 6,361，少 634 个可见像素。
- 真实生成 0/9/18px 完整 RGBA 和局部放大帧。三帧在近眼 ROI 都不存在新透明洞。
- 另制作三个几何刘海遮挡候选 A/B/C，并放大检查。三者都存在可见多边形拼接线：**全部拒绝**，不加入正式候选。
- 保留此前 LaMa 皮肤底图的文件 SHA 和像素；不重复模型生图。发丝保留在底图中，不叠加虚假的独立刘海。
- 视觉结论：下眼睑修边有所进步，但刘海与近眼在不同位移下的真实动态遮挡仍未打通；尚有睫毛、下眼缘细节差异。**视觉门禁仍未通过**。

## 验收
- P15-65 新增 13 项测试，验证来源/底图/前一版眼层 SHA、图层 RGBA、透明像素减少、0/9/18px 可复现合成和 0 透明洞、失败刘海不准入。
- Chromium 实际桌面/移动 2/2，HTML 图片加载 28/28、滑杆 0/9/18px 交互通过、页面错误 0。
- 输出 HTML 审查包包含三档移动图、遮罩、独立近眼层、修边对照及三张拒绝的刘海遮挡样例。
