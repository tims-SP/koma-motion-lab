# P15-86 · 原始睫毛与 SAM3 前发语义所有权修正

## 核心诊断
- Git 基线 ede2b4e，P15-84 隐藏底图仍残留固定眼睫毛。P15-70 的相同视角原始干净额头素材在该处没有旧睫毛。
- 初次仅引用 P15-70 同位置像素修复底图仍有细线，因为 SAM3 前发层也误包含旧睫毛。修复必须同步更改底图和前发语义归属，而不是追加更多皮肤补绘。

## 实际执行
- 在已检查的外眼角局部，复用 P15-70 相同坐标的干净像素替换 P15-84 遗留旧睫毛，移除 SAM3 前发层内的错误旧睫毛 Alpha；不新调模型、不进行纹理克隆，不触及其他头发和五官。
- 将 391 个源像素从固定前发所有权移给独立近眼；维持每个像素唯一所有权，保存新 face/eye/bangs/clip 独立 1024x1024 RGBA 图层。
- 0px 真正由四张新独立 RGBA 图层重组，可见 RGBA 与原画逐像素一致，整张 Alpha 完全一致。透明 RGB 的源 PNG 隐藏字节差异不宣称一致。
- 不带眼睛的背景与刘海组合，旧睫毛深色像素计数从 8 降为 0。
- 9/18px 重新渲染，两档分别改变 336 个可见像素，脸部 ROI 新增透明洞均为 0；不再有原先固定短线。
- 但视觉检查发现修正局部暴露新的前发/脸部竖向接缝。当前工程可检验、视觉未合格，候选不进入正式 ArtMesh/VDD。

## 验收

- Chromium 桌面/手机 2/2，HTML 图片 30/30 加载，0/9/18px 交互正常，页面错误 0。
- HTML 保留旧静止残线、清理后的底图与前发、新所有权、动态画面和新竖缝对照。
