# P15-62 · 近眼隐藏底图与 18px 位移实验

## 输入与目标
- 输入：P15-56 相对 +20° 右向候选，1024×1024 RGBA。
- 最小能力：将近眼作为独立层移动 18px，原位置应有完整皮肤底图，无透明孔、重影或明显纹理接缝。

## 执行
- 从原候选分离一个近眼多边形 cutout。
- 使用同一候选面颊区域做局部纹理复制、颜色均值匹配和 8px 羽化，制作诊断性 underpaint；没有把它冒充 AI 补绘或独立原画。
- 将近眼层右移 18px 并合成，验证原眼位置透明洞、遮罩覆盖和遮罩外像素变化。
- 工程结果：ROI 内透明洞 0，遮罩多边形内不透明覆盖缺失 0，遮罩外像素变化 0。
- 视觉检查：原眼位置被填充，但面颊复制区域在放大图中产生明显粉色多边形/纹理接缝，缺少原有眼周阴影与发丝细节。视觉门禁 FAIL，不能用于正式 ArtMesh。
- 曾尝试 Hugging Face Qwen-Image-Edit-2511-LoRAs-Fast 的 Anime-V2 补绘。连接账户的 ZeroGPU 免费额度不足（请求 120s、剩余 0），没有取得可用生成结果；模型输出未进入正式资产。
- 正式 P0 原画、正式 ArtMesh、VDD Keyframe 均未修改。

## 验收
- 新增 11 项单测，检查来源 SHA、RGBA 尺寸、18px 位移、零透明孔、遮罩内覆盖、遮罩外像素保护、失败准入状态。
- Chromium 桌面/移动 2/2，10/10 图片加载，0 页面错误。
- HTML 对照原图、underpaint、位移后预览及两张独立实验图层。

## 结论与 P15-63
简单 patch cloning 可以在工程上填满像素，却无法恢复眼周原画细节，不能当作最终方案。
下一阶段转为真正的局部生成式 inpainting：先对眼部建立精确 mask 和固定参考区域，使用有可用算力额度的 inpainting 服务，只允许改变近眼被遮挡区域；再将模型输出裁入 underpaint，验证 mask 外像素零变化、身份和眼周纹理自然。若无可用推理额度，先用可用的独立参考原画/人工补绘，不再把纹理复制当作通过。
