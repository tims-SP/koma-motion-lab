# P15-61 · 新 65° 候选语义 ArtMesh 拆层真实性验收

## 实际输入
- Git 基线 7e10257；P0 45° 原始 RGBA 原画，P5 45° 13 类 ArtMesh 旧部件。
- P15-56 相对 +20° 新候选：真实模型原画、独立金色交叉发夹及局部 RGBA 修复。
- P15-60 已证明整图 Crossfade 中间帧有双眼、鼻和脸型重影。

## 本轮真实实验
- 检查 P15-41 等现有右侧候选的 13 类 RGBA 图层：它们属于旧候选/旧配准，不能当作 P15-56 新原画的独立语义层。
- 在新候选中制作近眼、远眼、鼻、嘴、呆毛五个透明可见 ROI，另读取 P15-56 已独立分离的发夹 RGBA 图层及其遮挡底图。
- 互斥可见 ROI 抽取后的剩余图像仅为可见像素的残留合成，不包含隐藏皮肤、眼白、发根等原画。回拼所有可见 ROI 后 RGBA 与原输入像素完全一致。
- 单独把近眼 ROI 右移 18px：原近眼区域露出 1885 个透明缺口像素，眼周皮肤和发丝边缘突变。实际输出 PNG 可直接复核。
- 因此“可见 ROI + 透明 PNG + 精确回拼”不是独立 ArtMesh。五个 ROI 缺少干净语义边界和隐藏 underpaint，不能用于正式视角形变。
- 目前具备部分独立图层与底图的只有金色交叉发夹，其挂载画质仍有待确认。
- 正式 P0、VDD Keyframe 和 ArtMesh 均未修改。

## 验收
- 新增 10 项单测：哈希、裁切 RGBA、完全回拼、移动近眼破洞、发夹独立层、缺失 underpaint、准入禁止。
- Chromium 桌面/移动 2/2，22 张图加载，无页面错误。
- HTML 包含源面部、新候选、近眼移动破洞、五个可见切片、发夹独立层与回拼原图。

## 结果与下一阶段
语义 ArtMesh 门禁 FAIL。核心瓶颈是生产具备无遮挡底图的五官及头发独立原画，而非增加遮罩脚本、插值和质量测试。

P15-62 只做近眼及其下皮肤的最小实验：建立具备 underpaint 的近眼独立图层，验证右移 18px 后无透明破洞且画面自然。通过后扩展远眼、鼻、嘴、前发；失败则调整绘制方案。
