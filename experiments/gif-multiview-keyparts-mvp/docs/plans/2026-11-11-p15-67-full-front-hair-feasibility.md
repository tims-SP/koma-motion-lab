# P15-67 · 同视角完整前发提取可行性验收

## 实际输入
- Git 基线：8c53481；当前 P15-56 右向原画（1024x1024 RGBA）。
- P15-63 已有 LaMa 神经隐藏皮肤仅覆盖近眼，P15-65 已有独立近眼层。
- P15-41 存在旧角色视角的 1024x1024 前发层，但它不是当前 P15-56 合成原画的同源可验证图层，不准作为真实前发目标。

## 实际执行
- V1：基于原画可见粉紫头发颜色和粗略头部语义包络抽取完整前发区域，产生透明前发候选、Alpha 遮罩及 0/9/18px 实际组合图。
- V1 可见非透明像素 107158，bbox [432,104,783,575]。放大及单层审查发现发顶左侧粗切、近远眼色素被误提入头发；不能作为独立前发。
- V2：采用近远眼保守排除区，从 V1 遮罩中去除双眼污染，得到 97237 个非透明像素，bbox 保持 [432,104,783,575]，可见污染有所减少。
- V2 同样失败：去除眼部污染的保守遮罩也同时移除了本应覆盖眼睛的真实细发丝，无法建立准确 z-order；没有补齐发顶被粗轮廓截断的部分，也缺少可供前发移动后显露的额头和发根 underpaint。
- 已实际生成两轮透明 PNG 与遮罩、单层视觉图及 0/9/18px VDD 局部模拟。V2 图像保留的是实验性可见像素分区，不是独立绘制的发丝或真实 VDD。
- 正式 P0 身份原画、正式 ArtMesh 与 VDD Keyframe 未修改。

## 验收
- 新增 15 项单测，验证原画、旧前发、已批准近眼底图的 SHA；RGBA 与遮罩完整性；V2 排除面积；三档帧存在；缺少隐藏原画和准入拒绝。
- Chromium 桌面与移动端 2/2，18/18 图片加载；0/9/18px 浏览器滑杆实测通过，无页面错误。
- HTML 审查包明确展示 V1 带眼睛、V2 局部刘海缺失、额头底图不足及实际组合结果。

## 结论和下一阶段
完整前发的纯颜色分离方案不满足本项目高质量动画目标。停止重复尝试简单阈值/多边形以冒充语义分层。

下一阶段 P15-68 的关键输入应是真正匹配当前 P15-56 原画的**发丝级 Alpha Matting 或独立绘制/生成的完整 front-hair 透明层**，并使用局部 Inpainting 生成被它遮住的额头与发根底图。核心验收是原画在 0 位移可高质量重组，眼部 9/18px 时发丝在正确层级自然遮挡、没有眼睛重影和透明孔。只有视觉门禁通过才录入正式 ArtMesh。
