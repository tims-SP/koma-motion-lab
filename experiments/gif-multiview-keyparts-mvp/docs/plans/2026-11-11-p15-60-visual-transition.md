# P15-60 · 名义 yaw 45°–65° 视觉连续性门禁

## 实际执行
- 从 Git 74b0a22 继续，核对 P0 45° 基准及 P15-56 右向相对 +20° 透明候选 SHA256。
- 将名义 VDD 参数 yaw 45→65 与物理相机 yaw 分开；不再要求未标定的绝对空间角度。
- 使用两张 1024x1024 RGBA 原画进行预乘 Alpha 整图混合，生成 45、47.5、50、52.5、55、57.5、60、62.5、65 九张图和面部裁切。本方法仅用于诊断，不等同于分层 ArtMesh/VDD。
- 45° 与目标候选两端帧像素与输入完全相同。
- 中间帧尤其名义 55° 可见两套虹膜、睫毛轮廓重叠，以及鼻尖和脸部线条重影。整图 Crossfade 视觉门禁 FAIL。
- 端点 Alpha 支持区域 IoU=0.882312，眼部 ROI 两端平均灰度差约 49.49，仅作差异诊断。
- 交互 HTML 可用滑杆切换九档角度与面部局部。桌面和移动浏览器均实测滑杆 55→65→55，0 错误。
- 未替换正式 65° 关键帧或正式 ArtMesh。

## 结论
- 对于统一参数 VDD，物理 yaw 不可辨识不应阻挡视觉 MVP；但将参数叫 65° 不会让未批准原画自动通过。
- 真正阻塞是 45° 和当前右向候选的五官、脸型、头发与遮挡部件缺少可用于几何连续过渡的独立对应关系。
- 不允许将整图线性混合的九帧视为正式动漫输出。旧 P15-31/P15-33 的 443px 分层 VDD 以未通过的旧关键帧为基础，不能证明新候选已完成艺术准入。
