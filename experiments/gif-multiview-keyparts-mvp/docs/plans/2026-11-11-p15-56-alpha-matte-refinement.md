# P15-56 · 发夹透明边缘精修

## 实际结果
- 沿用 P15-55 选定的 -28px 发夹挂载与原有头发底图；未重新生成角色，未修改正式 ArtMesh。
- 检查发现独立发夹素材外缘自带粉色 matte fringe。直接叠加到粉色头发时，造成发夹边缘双线/粉色 halo。
- 对独立发夹 Alpha 通道做 1px、2px、3px MinFilter 收缩对照。RGB 金属颜色数据保持原样，未重绘金属渐变。
- 选定 2px：Alpha 非透明像素从 3856 减少到 3081（775 个边缘 matte 像素被清除），bbox 从 [691,279,760,370] 收至 [693,281,758,368]。交叉臂仍完整；3px 开始明显削弱圆头，1px 仍留较多粉边。
- 在浅灰、蓝、粉三种背景检查 1024px 全图；角色身份特征、粉紫短发、金色交叉发夹、双眼及制服均保留。局部 4x 放大仍可见原生成头发轮廓的少量锯齿；没有以局部蒙版改动角色其他部分。
- 本轮是边缘 alpha 修复，不是相机校准。绝对 yaw 65°、身份跨视角一致性仍未独立通过，不能批准正式关键帧。

## 验收
- 11 项单测通过：源素材哈希、RGB 不变、Alpha 单调收缩、三档输出、透明合成确定性、选定哈希、三背景尺寸、未批准状态。
- Chromium 桌面/移动 2/2；16 张图片加载，0 页面错误。
- HTML 审查包含 1/2/3px 局部对照、独立 RGBA 发夹、透明合成及三背景全图。
