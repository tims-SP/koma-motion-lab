# P15-57 · 45°–65° 多视角身份连续性审计

## 实际核查
- 读取 P15-38 13 个角度（45° 至 65°）的视觉审查与扩展 ArtMesh QA、每角度整图、独立发夹素材，以及 P15-56 当前候选。
- 原始角度覆盖：45、47.5、50、52.5、55、56.25、57.5、58.75、60、61.25、62.5、63.75、65。
- 所有 P15-38 角度的艺术验收字段均为 false；整条弧线 fullArtistAcceptance=false，独立绘制关键帧批准数 0。
- 47.5°/50°/52.5° 三个插值帧 Alpha IoU 约 0.978–0.981。该数值只反映轮廓重叠，不证明五官/身份连续性。
- 57.5°–65° 整图预览出现明显的眼睛、脸皮、头发遮挡合成瑕疵；不能用这些旧整图作为 P0 身份的正确性真值。
- 45° 原始图 SHA 与 P15-51 相机 LoRA 的源图 SHA 一致（78a08d5…），可继续作为 canonical 45° 身份参照；但扩展 QA 的 sourceP0HeroSHA256Verified=false 说明 P15-38 自身来源登记仍不完整，需补齐可验证来源链。
- P15-51 是从 45° 输入、LoRA 相对旋转 +20° 得到的更侧向候选。它是相对角度条件生成结果，不是经外部相机标定的绝对 yaw 65°。
- P15-56 的 2px alpha 发夹修复只改善局部 matte，不会修复上述整图五官和相机角度缺口。

## 结论
当前 P15-38 45°–65° 工程弧线不是艺术验收通过的身份序列。不可把高角度坏合成当成身份模板，也不可把 Alpha IoU 当成身份指标。保留 P0 canonical 45° 和 P15-56 新候选；拒绝把 65° 写入正式 VDD。

## 下一步 P15-58
1. 复核并补齐 canonical P0 45° 原画的来源 SHA/QA 绑定，保证身份基准可信。
2. 仅以 canonical 45° + P15-51 明确的 +20° LoRA 控制重新评估侧向候选；检查两眼遮挡、鼻梁轮廓、脸颊/下颌与金色发夹侧别。
3. 用独立几何/相机标定数据求绝对 yaw；没有独立标定时只标记为“相对 +20° 候选”，不宣称 65°。
4. 高角度整图仍有拼接瑕疵时，回到独立部件层修复，不使用 P15-38 失败的整图合成作基准。
