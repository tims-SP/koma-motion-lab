# P15-79 · 同视角眉毛独立像素层

## 核心诊断
P15-70 的 forehead-seam-repaired.png 已含原画眉弓。此前把眉毛视为缺失素材会导致重复绘制。真正需要的是从现有底图提取可独立寻址的眉毛像素，同时保留眉毛固定在头部、刘海在其上方的原有遮挡关系。

## 实际执行
- 在同视角底图 x=584..631、y=416..430 范围按原画深棕色笔触提取眉毛，形成 500 个非透明像素的 RGBA 子层。
- 通过互补 Alpha 将底图拆为 eyebrow.same-view.png 和 forehead.without-eyebrow.png。重组结果与 P15-70 原底图 RGBA 逐像素一致，未重绘眉毛，也未改变颜色。
- 动态层级为：互补额头底图 + 固定头部坐标眉毛 + 眼睛移动 + P15-75 pose-weighted 前发 + 发夹。
- 0px 与 P15-56 原画逐像素一致；9px 和 18px 分别与 P15-75 已验收动态帧逐像素一致；眼部 ROI 新增透明洞 0。
- 实际视觉复核显示：眉毛已经独立可寻址，但现有刘海 alpha 仍有碎片/虚线状边缘，眼眉交界没有达到高质量语义遮挡。因此仅通过眉毛资产拆分，不通过完整头部动态视觉门禁。

## 验收
- 新增 16 项测试：来源/资产 SHA、眉毛像素数与边界、底图精确重组、0px 原画、9/18px 参考帧逐像素一致、透明洞、正式资产禁入。
- Chromium 桌面/移动 2/2；HTML 图片 12/12；0/9/18 滑杆可用；无页面错误。
- 审查包包括眉毛独立透明层、互补额头、0/9/18 全画面与放大对照。

## 下一阶段 P15-80
眉毛不再重复提取或重绘。关键阻塞缩窄为 P15-74/P15-75 的前发 Alpha 语义质量：定位刘海在眉弓和眼尾附近的错误透明/碎片边缘，修正前发层；保留眉毛在头部坐标、眼睛独立运动。0px 保持源画逐像素一致，9/18px 放大无碎线和漏底后再考虑正式 ArtMesh。
