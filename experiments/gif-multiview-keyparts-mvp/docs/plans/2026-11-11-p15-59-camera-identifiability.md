# P15-59 · 相机绝对朝向可辨识性验收

- 核对 Git 2e21bb0、P15-58 的 45° 身份基准、P15-56 相对 +20° 候选、P15-12 相机代理源码及 P5 landmark-qa。
- 12 个锚点中，10 个由名义 0°、45°、90° 图像坐标反算正交代理 (c,X,Z)；远眼、发夹两个使用二维线性外推。P5 的原始观察来自 PSD Alpha 连通域和 P0 GIF ArtMesh 锚点，而非具有世界坐标定义的实测三维面部点。
