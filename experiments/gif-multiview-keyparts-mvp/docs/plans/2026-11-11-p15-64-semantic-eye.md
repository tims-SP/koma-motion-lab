# P15-64 · 近眼语义切片与前发遮挡审查

## 输入
- 以 Git 613a221 为基线，复用 P15-63 的真实 LaMa 近眼隐藏皮肤 underpaint-full.png。
- P15-56 右向角色完整 RGBA 原画仍是不可改变的身份源。
- 不重新调用推理、不改正式 ArtMesh 和关键帧。

## 真实执行
- 实际检查 1024x1024 原画的近眼、左侧发丝、眼白与睫毛，基于实际像素坐标制定局部轮廓。
- 第一版粗分层有 7,510 可见像素；移动后眼周呈现不自然的灰色多边形描边。基于 RGB 差异过滤的三档测试又损伤了虹膜下缘，判定不可采用。
- 收紧眼睛外轮廓并使用 1.5px 羽化；最终独立近眼图层保留 6,995 个可见像素，相较 P15-63 原 ROI 的 11,457 个减少 4,462 个。
- 未将自动提取的矩形前发层用于正式预览，因为该层移动时会产生清晰的方形边缘。前发仍保留在原始神经 underpaint 中。
- 以既有 underpaint 为底图分别生成 0、9、18px 的移动图，近眼位移 18px 的旧位置无透明洞。
- 图像实际放大核查：原来的皮肤岛、头发矩形残影显著减少；但近眼下眼睑局部仍有灰色晕边、睫毛上沿与刘海交界不完全自然，因此正式视觉门禁不通过。
- 生成交互 HTML，滑动控制 0/9/18px，同时显示原图、P15-63 失败图、改进版本及独立透明层。

## 工程验收
- 新增 13 项测试核对原源图哈希、神经底图未改、源 eye ROI、切片/遮罩 SHA、位移帧可复现、透明洞 0、旧 ROI 面积减少和拒绝正式准入。
- Chromium 桌面/移动 2/2，14 张图片加载，滑杆从 18px 变更到 0px 再返回 18px，0 页面错误。
- 本轮代码、验收和进度写入 Git。所有原画候选均在被忽略的 private-assets 目录，正式 P0 Hero、VDD/ArtMesh 未修改。
