## P0-2 生产准入规则

1. 每个键视角必须是独立绘制的完整图像，具备明确源图哈希；参考图板裁切只计入参考级。
2. 高分辨率必须由原生细节或审查通过的高质量重绘提供，单纯 Lanczos 放大只能改变画布尺寸。
3. 独立 RGBA 素材需验收透明边缘和同一画布尺度；完整安全边距目标每侧不少于 8%，原有半身服装的底部截断需要专门扩画。
4. 层级必须含可单独开关的头发、脸、眼、眉、鼻、口、耳以及必要的隐藏区域补绘；分离与重组必须在固定坐标下验收。
5. 建立每视角 landmarks、器官稳定身份、可见性和遮挡关系，随后才允许进入 PSD、ArtMesh/VDD 真实测试。
6. 保留独立 20°/55°/82° 留出参考给 HEAD009 的 T03B/T04，不能将参与插值调试的图作为独立验收证据。
