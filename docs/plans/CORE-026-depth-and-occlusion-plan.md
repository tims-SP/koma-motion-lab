# CORE-026：分部件深度、附着与遮挡校准

日期：2026-10-31（Asia/Shanghai）。状态：PLANNED，尚未执行实现或验收。

执行者mcode；Codex下明确工单、独立验收、提交恢复检查点。仅在tims-SP/koma-motion-lab的feature/koma-25d-core-021工作。媒体只进入ignored out/与owner-only Draft Release；git只存代码、工单、报告和文本证据。每个阶段无论通过或失败均提交。

## 目标与路线判断

让小角度头部运动出现可信的鼻/眼/脸缘相对位移、头发遮挡和耳根连接，同时保住原画与正面复原。先验收七个关键姿态及中间帧，再制作视频。当前CORE-025的艺术门禁FAIL保持为历史结论。

从现有代码确认的问题：

1. core025.js的makeGeometry对62层使用同一高斯深度场，再加order*0.001。图层序号同时承担了空间深度与绘画叠放两个不同职责。
2. 眼白、瞳孔、睫毛、阴影、高光等虽然分别建网格，却缺少共同接收面与附着约束；提高每层Z不能建立可信头型。
3. 所有core均depthWrite，fringe不写深度并按固定renderOrder绘制。不能认为这已经解决转动后的半透明排序。
4. Multiply派生纹理是在默认下层颜色上烘焙的。新姿态发生相对移动或遮挡变化后，默认烘焙不是正确混合的保证。
5. 七个旧锚点是source-attached位置，未证明位于有效alpha内、也未证明可见；不能直接当几何标注真值。

路线选择：保留Three.js、原画纹理和原始UV；建立少量有语义的接收曲面，用原生Inochi形变提供小角度美术约束。先比较分部件深度方案A；只有A无法达到参考中的轮廓/眼位变化时，再比较方案B（A加受限原生形变残差）。不直接换引擎，不把解决透明排序当作解决头型。

单张正面不能唯一确定深度。本轮深度是待校准的美术模型，不声称恢复真实3D。原生HeadYaw本身只支持有限的2D头部运动，也不是侧面设计真值。

## M1：建立可用对照与部件约束（先执行）

执行详细工单[CORE-026-M1-mcode-order.md](CORE-026-M1-mcode-order.md)。该阶段不改CORE-025渲染器。

1. 冻结CORE-025场景、配置、准备/捕获/验收程序、源文件与62层纹理的哈希，恢复原有0°/±15°图作为baseline。原始PSD、INX和已验收UV保持不变。
2. 读取真实Aka.inx，核验Head:: Yaw-Pitch外部范围[-1,1]、默认[0,0]、9×3轴与114绑定。固定raw pitch=0；采样raw yaw=-1,-.75,-.5,-.25,0,.25,.5,.75,1。
3. 以CORE-021修正后的参数域为准：raw[0,0]才是默认，内部网格为[.5,.5]。旧CORE-008里把0.5称为中立的描述不得沿用。
4. 复用锁定的Inox2D上游提交及已验证初始化修补，真实捕获上述9姿态；使用完整角色求值、完整头部显示。旧ear-only输出只能检查耳朵，不能当全头对照。保持相机固定，其他参数默认，物理与时间依赖明确固定或报告无法固定的因素。
5. 建立PSD order→INX UUID的映射。核对名称、纹理内容、坐标与绑定，不按名称相似或texture index猜测。62条必须都有状态；允许一对多/无对应，但需给出证据与原因。
6. 建立19项特征标注槽位：鼻尖、鼻根、下巴、左右嘴角、左右脸缘、左右各内眼角/外眼角/瞳孔、左右耳根/耳尖、颈部连接、叶柄。每项记录语义、原始层、参考坐标、alpha支持、标注置信度及可见性。无可辨认鼻尖等特征就标UNKNOWN，不能补造坐标；19是槽位数，不要求伪造19个可见点。
7. 只在默认姿态求一次全局平移/等比缩放，固定用于其他姿态。若PSD与INX默认布局无法这样配准，则仅使用已验证部件的相对运动，不把全头像素差当质量指标；保存配准残差。
8. 导出重叠关系表：before/behind、receiver、local mask、适用姿态、依据、置信度。默认图层顺序只证明默认叠画，不能自动升级为三维前后关系。

M1产出：source-audit.json、part-correspondence.json、reference-manifest.json、landmarks.json、occlusion-constraints.json、全头9姿态真实PNG与接触图。PNG进入out/core026/reference/；受控文本证据进入evidence/core026-M1/。

M1门禁：源哈希、参数域与实际捕获通过；所有62层有去向；脸13、鼻21、眼24–43及58–59、两耳1–2、侧发44/46、前发48/50/52/54/56、颈11必须有验证映射或明确阻塞原因。Codex看实际图后确认哪些参考可用。无法映射的部件不进入自动拟合。若无可用斜向对照，结束为BLOCKED_REFERENCE，仅可提交诊断，不能继续盲调Z或声称自然转头。

## M2：把绘画层整理为接收曲面与附着层

每个PSD层保留源身份，62条记录不能丢失；不要求62个相互独立的空间壳。H定义为默认姿态Face层有效alpha外接框的半宽，Z朝固定相机为正。所有参数以H或源像素为单位并写入JSON，不散落在代码里。

| 部件/原层 | 几何与运动关系 | 遮挡与合成要求 |
|---|---|---|
| Face 13 | 前额/双颊/下巴组成连续接收曲面，绕头颈连接附近轴转动 | 轮廓来自该网格上的真实alpha，不用整张头图遮掉失败部分 |
| Nose 21 | 鼻根附着Face；鼻尖局部前凸由Face几何支撑 | 鼻线只是绘画，不把这层PNG变成漂浮鼻子；无鼻侧面信息则限制可见范围 |
| 眼24–43、58–59；眉60–61；口22–23 | 眼眶、口眉附着Face；眼白/瞳孔/高光使用共同局部UV运动与眼部遮罩 | 睫毛/眼皮有局部层序；瞳孔不能穿出眼白；遮挡只有在参考支持时发生，不强制远眼消失 |
| 后发3–10 | 单独后发包络曲面 | 可遮耳根，但不得因为层序靠后就穿过Face；6只合成到接收层5 |
| 侧发44–47 | 左右独立发片及根部约束 | 45附着44、47附着46；按局部交叠解决脸缘关系，不整体换序 |
| 前发48–57 | 5束独立发片，根部接头皮、尖端允许小幅差动 | 49→48、51→50、53→52、55→54、57→56的高光跟随基础层；局部遮脸/眼关系保留 |
| 耳1–2 | 左右独立有曲率发片，耳根连接头部 | 先验证耳根、头发交叠；源图没有耳背时不扩展成有纹理耳背模型 |
| Neck 11–12 | 颈部接收面与下巴连接区，颈根固定，过渡权重归一 | 12附着11；转头时不能整块颈部随脸侧滑或露背景缝 |
| Leaf 62 | 叶柄连接发束/头皮，经参考验证 | 叶柄不漂浮；不凭最高layer order永远盖在所有物体前 |

阴影：14–20是Face上的接收阴影，不与对应刘海做同一世界空间位移；记录其来源发束和接收面。9项已知阴影裁剪关系沿用为默认姿态约束。11项MULTIPLY全部有清单，眉60–61也不得遗漏。

合成实现顺序：先做每个接收面内的局部RGBA合成，使用原始NORMAL/MULTIPLY与alpha规则；高光/阴影/眼部绘画在局部UV域运动后合成，再把接收面参加空间深度测试。不能简单把所有眼层永久烘成静态纹理。跨接收面混合需单独列出，不能默默用旧默认烘焙代替。若重现原画叠放需要额外局部层，保留并写明原因。

默认姿态必须先通过正面保真，才进入转头。局部接收面重组引起的损失需真实测量，不能因为架构更整齐放宽门禁。

## M3：比较两组深度，再决定是否需要形变残差

方案A从固定source XY/UV起步，只改Z、连接与局部遮挡；正交相机不改。Face采用椭球前表面/低阶连续曲面，源有效alpha内建立支撑，边界外平滑延拓；不因公式sqrt负值裁掉原有纹理。鼻部隆起连续并有鼻根过渡。

初始两组是搜索起点，不是测得的人体参数：

| 初始组 | Face中心至边缘深度差 | 鼻尖相对所在Face接收面前凸 |
|---|---:|---:|
| A-shallow | 0.55H | 0.10H |
| A-deep | 0.85H | 0.18H |

每组仅先调Face深度、鼻凸、颊宽、头部pivot、两耳根/侧发相对深度；后发/前发以M1约束限定，不给62层各开自由Z。Face深度搜索[0.35H,1.00H]、鼻凸[0.03H,0.22H]，其余边界由实际锚点/层域生成并写入配置。区间只是防止无约束漂移，必须以像素与目视结果选型；没有参考支持时不继续扩大区间。

同曲面的绘画层不能再用order*0.001累计厚度。只有确需独立绘制的贴附层允许epsilon，从1e-4H开始，最大1e-3H；这只是防冲突偏移，不能参与头型拟合。若稳定性要求更大offset，记为实现失败诊断。

旋转pivot从验证的头颈连接求得；固定相机与头部pivot，不用逐帧平移/缩放补救。先Face/鼻/眼，再发片，再耳根/颈部，按顺序各自保存诊断图；不要同时改所有参数。

方案B只在A无法匹配原生小角度美术运动时启动：将已验证的原生形变作为局部网格残差。先减去A已经产生的投影位移，再求需要的残差，避免把完整原生yaw位移和完整3D旋转叠加两次。残差绑定同一局部网格/蒙皮坐标，限制拉伸、三角形翻折及根部漂移；theta=0残差必须为0，原始UV不变。

原生raw yaw与Three.js yaw_deg分别记录。M1参考没有物理角度标定：若选定raw yaw与theta的对应用于拟合，它是ART_DIRECTED_CORRESPONDENCE，必须写明采样对应与依据；不得把raw=1标为15°真实头姿。B必须标为CURVED_SURFACE_PLUS_NATIVE_2D_RESIDUAL，不冒充纯三维恢复。

冻结4组比较：旧CORE025、A-shallow、A-deep、B（仅在启动时）；7个几何姿态-15/-10/-5/0/+5/+10/+15。先用0/±10拟合；±5和±15作为留出检查，不单独手调其锚点。与原生比较的姿态对应表一旦确定即固定，另报原生参考覆盖范围，不能据此宣布±15艺术通过。

## M4：遮挡、透明与缺失覆盖检查

1. 绘画层间的覆盖在接收面局部合成域完成；不同曲面的实体核心用真实深度测试。禁用整层突然renderOrder切换作为主要转头方案。
2. 单独输出depth、frontmost_part_id、每部件遮挡前coverage、遮挡后visibility、接收面mask与wireframe。ID诊断关闭混色与抗锯齿，以alpha>=0.5定义核心归属，alpha其余部分单独报告；不能用当前混色的part_id图当精确ID真值。
3. 把M1的before/behind约束限定到具体ROI/姿态，逐像素/射线检查双方实际覆盖和深度；只有alpha有效的三角形参与覆盖，透明矩形不能当实体挡住脸。关系形成环或同一对部件局部交叉时，拆局部区域/网格，不强制一条全局层序。
4. 半透明边缘先在同一接收面内解决；确需跨面混合的区域逐项列出，在黑/白/棋盘底检查。简单按mesh中心排序若失败，优先局部拆面；确认存在无法消除的跨面透明问题后再评估更复杂透明合成，不预先引入整套新渲染架构。
5. 每1°采样-15到+15，共31姿态，检查遮挡变化曲线和连续性。可见性随轮廓发生正常变化不算故障；没有几何/alpha依据的整片跳变或1帧闪烁必须返修。
6. 缺失覆盖分为EXPOSED_SOURCE_GAP（侧背无纹理）、DETACHED_ATTACHMENT（接缝）、SORTING_ERROR、SOURCE_ALPHA_ARTIFACT，逐项标位置/帧号。不能用自动补色、拉伸远侧像素、整脸淡出或强行缩放冒充已有侧面设计。
7. 仅处理可验证的派生alpha修整，源图颈部软边/游离片段另记；原始PNG不覆盖。0°修整变化须有差分审查。

遇到真实缺失侧面：降低可用角度到所有门禁通过的最大连续区间；生成“缺哪块/属于谁/需要哪个视向/UV接缝在哪”的补片需求。新补片另做图像编辑与身份/接缝验收，不自动接纳现有生成候选C。±15仍作为失败姿态保留，不能从报告中删掉。

## M5：验收、视频、复现与止损

数值阈值是本轮预先约定门禁，不是已完成结果。所有像素值在0..255域，位置误差折算到640×640画布。

| 门禁 | 要求 |
|---|---|
| 原画与0° | 原始文件/UV哈希不变；source/clean白黑底全图RGB MAE<=0.10、前景并集MAE<=0.50；最大差<=4；>16比例=0。必须同时报前景与全图，不能用背景稀释误差 |
| 关键点 | 在可用且固定配准的参考姿态，已验证可见标注平均误差<=2px、最大<=4px；报告置信度，未知/遮挡项不硬拟合 |
| 轮廓 | 在可用同姿态对照上Face ROI silhouette IoU>=0.98；参考/配准不可比则标BLOCKED而非写PASS；整头/耳发另报，不能用大背景充数 |
| 附着 | 眼部贴附、耳根、鼻根、叶柄、下巴/颈部各约束最大裂缝<=1px；纹理不被遮挡掩盖前先检查原始接缝 |
| 结构 | 所有实际使用网格有限数值、无非预期退化/翻折；几何朝向与投影分别诊断，轮廓处合法背向/自遮挡不误判为翻折；62源层均有可追踪去向；无未解释核心区域穿插/覆盖错误 |
| 连续性 | 31姿态和97真实视频帧无无依据跳层/闪烁；可解释的遮挡事件单独标注。回程0°与起点MAE<=0.01；相机/pivot固定 |
| 画面 | Codex独立看鼻/双眼/脸缘/刘海/耳根/颈部局部与视频；不能仍只像卡片摆动，不可出现明显漂浮、纸缝或闪片；数值PASS不能代替此项 |

若固定配准/纹理对应使某些上述绝对参考指标无意义，M1应先标记该指标BLOCKED并保存替代的相对运动诊断，不能在看到失败值之后偷偷更换口径。

先比较7姿态×2底色的beauty及关键姿态诊断；选择最佳合格方案后才录97帧/24fps视频。旧方案与选中方案同镜头并排，保留角度/原生控制值标签；对最终H.264解码13帧及关键局部复核。实际媒体进入Draft Release，文本验收证据提交仓库。

止损：M1无可信参考则停在映射/诊断；A两组和一次B局部返修后仍不自然，记录失败并转向明确的侧脸补片或更强原生2D驱动，不继续无限微调Z。没有可靠素材覆盖的角度不发布为可用。完整侧背、闭合头模、骨骼/IK与360°不在本轮完成声明内。
