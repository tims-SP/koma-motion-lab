# CORE026 Live2D外部视觉基线工单

日期：2026-10-31 Asia/Shanghai。依据[专项研究](../research/CORE-026-Live2D-skills-and-autorig-survey.md)。这是外部自动绑定候选的有限视觉对照，不是自研M3拟合启动、主线引擎迁移或已完成结果。

1. 在ignored out/中的独立目录准备候选。第一条路线固定live2d-agent-kit@354d95800b7d498246dfb658e0e2ee379c29caa4及其engine-lock中的psd2live@5526f2e16b57e5f83d34f33730d6fa26d8bc8695，按对应补丁核验。第二条PSD2Live最新无窗口路线固定d5d2047d3865ee92679a81501861ff79ae644a2a，使用独立目录，禁止混套kit补丁。不安装全局个人skill，不修改生产库。
2. 先核对JDK21/构建工具、浏览器和平台匹配的Core是否可用；读取真实命令的能力与失败日志。用上游最小几何示例做实际导出和目标运行时渲染。MOC一致性、顶点求值、真实PNG各自报告；静态四边形或placeholder不算可绑定角色通过。缺依赖就记录具体BLOCKED，不转成假成功。
3. 只读现有AkaPSD/INX及62层合同。新建候选映射表：每层order/UUID/来源SHA、位置、语义、Multiply/clip/接收面去向。需要改名或组合时只生成派生副本并记录，不改原始PNG、UV、原生参考或旧CPU/浏览器基线。62来源、11Multiply、4native clip、9派生阴影不得静默丢失。
4. 导出候选并先渲染默认source/clean×白/黑。使用明确固定相机/坐标对应与旧基线按现有RGB/alpha门禁比较；图集重采样、混合不支持或眼域裁切导致失败须保留。不能随意放宽阈值、拿新候选自比或全局变换掩盖部件错位。目标格式表达不了的内容分列BLOCKED/FAIL。
5. 默认可比后，对头转控制采集默认及左右半幅/全幅、0复位；控件数值只视为参数值，不把AngleX名称或标称30直接当实测物理角度。检查实际可见的鼻、双眼、下颌、眉发、耳/叶/颈贴附；改变参数但只动透明顶点不能算会转头。关闭随机idle/物理后先检查确定性。
6. 输出49帧/24fps的短往返对照及关键帧表、实际参数轨迹、每帧PNG SHA；解码抽检并看接缝和透视。只有仍未注册的姿态只能作定性对照，不能冒称与原生raw yaw的物理角度对应。记录视觉FAIL，即使Core可加载或所有参数都驱动网格。
7. 若主候选因构建/格式失败，可在同一受控预算内试iki@3d0701733e9d0eb6a2e12a609d8b456626ed8ac0；仍使用现有源层和独立语义映射，检查其warp/eye-white mask是否削掉原画。它是.iki开放2D候选，不计作MOC3/真3D通过；每条路线各自输出事实，不把降级伪装成原目标完成。
8. 汇总三类结论：默认保真、运动画面、运行时/格式。依据实际对照决定复用作者工具、提取warp/拟合算法或保留自研路线。主线完整M2B、M3、31姿态动态遮挡与97帧成片验收仍按原计划独立判定；49帧外部基线不冒充M5完成，360不放行。
