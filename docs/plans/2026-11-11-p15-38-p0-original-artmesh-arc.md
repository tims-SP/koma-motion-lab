## 阶段目标

将已冻结的 P0 45° 原始动漫绘画作为真实角色/相机身份起点，接入 P15-37 已校验的 55°–65° 原画局部驱动 ArtMesh，形成可追溯、全角度逐层审查的 45°–65° 连续候选动画。相比只使用整体图片混合，沿用同一组 13 个 ArtMesh 角色 ID 和固定图层绘制顺序，以保留面部、眼睛、发夹和头发的来源关系。

本阶段工程验证相机视角接续、原始关键帧保持、分层形变与实际 Chromium 渲染；正式画质需通过独立原画与隐藏笔触视觉门禁。

## 形变与合成策略

`scripts/p15_38_extend_p0_arc.py` 将 P15-20 的 45° 1024×1024 RGBA 图层分别转换为 443×443 原生工作空间。对 45°–55° 的每个语义部件分别执行 OpenCV Farneback 双向光流：原始 45° 到 55°、原始 55° 到 45°。根据目标角度将原画像素按光流平移到中间位置，最后用预乘 Alpha 进行 RGBA 合成，减小透明区域对颜色的干扰。

对于 45° 完全不可见的耳朵等部件，保留其原画 Alpha 归属，由两端原图透明度控制渐进显现，不制造不可见部位的虚构笔触。单像素流动幅度限制在 16 个 native 像素，跨角度的 13 层深度归属保持原始角色 ID 和绘制顺序。

| 角度 | 角色来源 | 验收用途 |
|---|---|---|
| 45° | P0 原始绘画与 P15-20 13 张 RGBA | 真实来源关键帧 |
| 47.5° | 45° / 55° 双向部件光流 | 新中间帧 |
| 50° | 45° / 55° 双向部件光流 | 新中间帧 |
| 52.5° | 45° / 55° 双向部件光流 | 新中间帧 |
| 55° | P15-37 保存的 13 层 | 原图字节一致 |
| 56.25°–65° | P15-37 保存的 8 帧 | 原图字节一致 |

本阶段只对 45°–55° 新增三张局部补间，保留已有 55°–65° 的完整源数据。

## 既有研究的对接方向

- [LayerInbetween](https://github.com/MarkMoHR/LayerInbetween)（ACM TOG 2026）：显式分层与被遮挡笔画对应，提供成熟的精细补间方向；本阶段只复用思想，实际使用轻量化角色级双向光流。
- [See-through](https://github.com/shitagaki-lab/see-through)（SIGGRAPH 2026）：支持语义图层和不可见区域补绘的 PSD 输出。它明确区分自动分层与后续手工可控的角色绑定，适合作为下一阶段原画质量对照。
- 现有 P15-37：已完成 57.5°、60° 的局部新 RGB 原画注册与局部 ArtMesh 连续性工程审查。
