# P15-07 · 多视角原画几何与 ArtMesh 对应验收

版本：2026-11-10
角色：`p0_character_001`
实验：`experiments/gif-multiview-keyparts-mvp/`
正式渲染基线：P8 语义 ArtMesh
执行分支：`feature/gif-multiview-p0-ingestion-20261105`

## 目的

分别测试 **关键帧几何重投影** 与 **13 个语义 ArtMesh 的短弧形变**，用真实原画和真实 Chromium 画面评估轮廓、眼鼻、头发、耳、衣领的视角对应。原始 P0 关键原画必须保持逐像素不变。工程门禁和画面质量门禁分别核定。

## 输入与来源角色

| 角度 | 输入来源 | 用途 |
|---|---|---|
| 0°、45°、90° | P0 原始 SHA 注册源图与 P5 语义分层 | 原始关键帧与既有工程基线 |
| 67.5°、72.5° | P14 原画候选及其 13 层 ArtMesh | 第一组几何重投影实验的训练关键帧；第二组短弧实验的独立于当前渲染器的参考 |
| 65°、77.5° | P15-06 Qwen-Image-Edit-2511 绘制候选、26 张 RGBA | 第一组几何实验的留出角；第二组短弧实验的训练关键帧 |
| P0 Hero | 预期原始 SHA：`e95a4b694777f4dcd2e085b25b10d76058d65cd1f8c6ef46971caa8005cb7e54` | 正式身份源复核门禁；仍待原图字节恢复 |

两组实验的关键帧角色不同。同一图像一旦作为渲染关键帧，不再视为该组实验的独立留出角。P14 67.5°/72.5° 当前仅作为绘制候选比较，不代表已批准艺术真值。

## 第一组：源原画几何重投影

`scripts/p15_07_geometry_bridge.py` 使用真实 0/45/67.5/72.5/90 原画，计算双向 DIS 光流。比较：

- 单源笔触传输；
- 双源 premultiplied RGBA 混合；
- signed-distance 前景轮廓内插；
- P14 语义原画颜色传输。

测试在 65°、77.5° 使用独立 P15-06 绘制图作为对照：

| 算法 | 65° IoU | 77.5° IoU |
|---|---:|---:|
| P8 既有语义 ArtMesh | 0.730488 | 0.855089 |
| P14 既有语义关键帧 | 0.838007 | 0.858436 |
| 新几何单源 | 0.848101 | 0.872452 |
| 新几何双源 | 0.846072 | 0.873461 |

新几何在两角度均改进轮廓，65° 头部裁剪 IoU 为 0.902446，77.5° 为 0.896976；完整角色均未达到 ≥0.90 的独立视角门槛。光流对眼、眉、口与发束仍有非刚性误对应，因此只保留为工程对照。

## 第二组：新增 65°、77.5° 原画关键帧的短弧实验

采用 P0 原始 45°/90° 与 P15 65°/77.5° 绘制候选，分别实现：

1. `scripts/p15_07_semantic_keyframes.py`：13 层 ArtMesh 部件 ID 与深度一致、独立短弧光流、遮挡显隐、SDF 前景边界。
2. `scripts/p15_07_wholekey_preview.py`：整图光流与 SDF，仅用于诊断几何，与正式语义渲染分离。
3. 两条路线各自输出 0°–90°、每 2.5° 一帧，共 37 帧，合计 74 帧。
4. `review/p15-07-view.html`：交互式 HTML 对照 P8、语义 ArtMesh、整图几何和绘制视角。
5. `scripts/capture_p15_07.cjs`：实际 Chromium 截图 8 个角度、共加载 28 张原画/渲染图，页面错误与失败请求均为 0。
6. `scripts/p15_07_review_qa.py`：检查原画及逐帧来源 SHA、关键帧像素零差异、RGB 相邻帧变化、Alpha 轮廓及 P14 绘制候选对照。

参考绘制候选的轮廓比较：

| 角度 | 分层 ArtMesh IoU | 整图几何 IoU |
|---|---:|---:|
| 67.5° | 0.862236 | 0.864352 |
| 72.5° | 0.841151 | 0.851177 |

37 帧时间序列工程诊断：

| 渲染方法 | 相邻帧 RGB 平均变化中位数 | 峰值 | 2.5 倍中位数以上 |
|---|---:|---:|---:|
| 语义 ArtMesh | 5.3762 | 12.9870 | 0 |
| 整图几何 | 5.8665 | 16.1350 | 1 |

这些统计只覆盖色差与可见轮廓，不替代五官解剖与笔触连续性评价。

## 视觉抽检结论与发展路径

原始 45° 为偏正面的双眼视图，65° 绘制候选已接近单眼侧脸；该 20° 区间的面部拓扑、远眼显隐、耳根、刘海、领口变化很大。真实渲染显示，约 55° 的局部区域不能仅靠当前 DIS 与排他像素层解决；67.5°、72.5° 的语义层间仍有头发和颈部错位。整图几何中相邻侧脸较稳定，但不能表达可编辑部件的真实遮挡与隐藏补绘。

下一阶段 P15-08 首先补齐 **55° 真实绘制关键帧、13 张同画布语义 RGBA 部件与头/眼鼻口/耳/发束/衣领锚点**，并明确视角的解剖、面部形态和物理左右关系。

最低输入合同：

- 身份参考优先 P0 已批准 Hero 与经过哈希确认的原始 45°/90°；Hero 源 SHA 复核单独登记。
- 目标 55° 应在原始 45° 的偏正脸和 65° 单眼侧脸之间，远眼逐渐被鼻梁和刘海遮挡；鼻梁、鼻尖与下颌转向遵循空间结构。
- 13 张透明 `1024×1024 RGBA` 原画严格对应单一语义部件；同一部件跨帧坐标统一；眼、耳、发夹维持角色物理左右 ID。
- 单独保存隐藏补绘 `hair.back`、`face.skin` 与远侧器官，避免部件运动后显示透明孔。
- 新 55° 是新关键帧，不计入自身留出角。独立验收角度应另行取得例如 52.5° 与 57.5° 的真实原画或精确原画标注。
- 重新进行 0°–90° 全 37 帧 Chromium/HTML、时间连续性、关键原画保真、轮廓及解剖质量签收，完成后才进入全周扩展。

技术参考：[LayerInbetween](https://github.com/MarkMoHR/LayerInbetween)（SIGGRAPH 2026），其“分层/遮挡感知笔触对应、全局-局部变换”的框架适合后续对应关系研究。此实验沿用已安装的 OpenCV DIS、P5 锚点与当前语义 ArtMesh 实现，未引入模型推理依赖。
