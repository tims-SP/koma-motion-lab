## 确实发现并退回的错误

- 轻量模式不提供文件/命令工具，切换标准模式后才实际执行。
- 仿射矩阵排列错误、Pillow AFFINE 不支持 LANCZOS，以及不必要的自制采样器。
- 全透明调色板 PNG 被读成黑图；现改为先经 RGBA 在白底合成。
- 原图和可变运行清单同时被替换可绕过核验；现以已提交的 source_freeze 为准。
- 源/目标别名可能覆盖原文件；现提前拒绝同路径、软链接和硬链接别名。
- 字符串子串判断错误接受空配置；改为精确合同匹配并加入回归。
- 修复字符串判断时误伤合法 tuple 配置，导致整套测试失败；再次退回并重跑。
- 把目录存在、乃至 64 字节伪造 `.safetensors` 当成完整模型；现只报告文件存在，
  完整性和加载验证未执行时绝不赋予模型就绪 PASS。
- HTTP 200 的 HTML/无效 JSON 被当成 API 可用；现明确验证元数据结构。
